The thesis

People eat with their eyes first — so the menu has to make them hungry.

A QR menu isn't a document, it's the moment of decision. Research on 2026 digital menus is blunt about it: motion and imagery trigger genuine appetite cues, and impulse dining lives or dies on how fast a screen gets someone from "I'm hungry" to "added." Our edge over MenuScan, DineOpen & DotPe isn't features — it's that our menus look designed and feel alive, while theirs look like a spreadsheet with a logo.

1

Appetite over information

Warm reds, oranges and golds measurably stimulate hunger. Hero the dish, not the database. Photography (or a tasteful illustrated stand-in) does the selling.

2

Speed to "Add"

Every screen shortens the gap between craving and cart. Sticky category rail, one-tap add, running total always visible. Friction is lost revenue.

3

Motion with a job

A pulse on add, a gentle steam loop on a bestseller, a skeleton while images load. If an animation doesn't clarify, guide or confirm — it's cut.

4

Made for the real phone

16px+ text, 44px tap targets, lazy-loaded WebP, works on a ₹8,000 Android on 3G. A beautiful menu that won't load is worthless in a dhaba.

Color psychology

The palette does the persuading before a single word is read.

Each template is built on one of these appetite strategies. The point is range: a fine-dining bistro and a highway dhaba should never be handed the same colors.

Typography · the Indian reality

Every template ships bilingual-ready.

A dhaba's items are Chole Bhature, छोले भटूरे. Most competitors break on Devanagari. We pair a characterful Latin display with a font that also carries Hindi/regional scripts — so the same menu reads beautifully in both.

The build strategy · for a solo founder

Don't build 20 menus. Build one engine, ship 20 themes.

Every card above is the same component fed a different token set — palette, fonts, radius, shape. That's the whole trick, and it's what keeps this maintainable for one person: adding template #21 is a data file, not a new codebase. Owners pick a theme; the menu data never changes.

01

Owner registers

Restaurant name, logo, table count.

02

Picks a template

From this gallery. Live preview with their own items.

03

Adds the menu

Categories, dishes, prices, veg/spice tags, Hindi names.

04

Generates QR

One per table, table number baked in, print-ready.

05

Goes live

Scan → order → kitchen → WhatsApp bill. Payment toggle optional.

Non-negotiables · every template must pass

The quality bar that beats the ₹129 crowd.

  • Loads in under 2s on 3G; images lazy WebP with skeletons
  • 44px+ tap targets, 16px+ body text, thumb-reachable cart
  • Bilingual: English + Hindi/regional item names
  • Veg / non-veg / Jain / spice indicators standard
  • Motion respects prefers-reduced-motion
  • Text contrast ≥ 4.5:1 in every palette
  • No app install — works in any phone browser
  • Runs at 40 tables or 400 from the same theme
